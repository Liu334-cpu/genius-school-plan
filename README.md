# 启明一中：逆袭成长计划

一款以高中三年为背景的校园成长模拟游戏。

你将以一名刚入学的高中生身份进入启明一中，在周制推进的校园生活里，一边应对月考、竞赛、老师、家庭和人际关系，一边决定自己最终会成为什么样的人。

这一次，你不一定是学霸开局。
你可能是尖子生，也可能只是普通生、后排生，甚至是从学渣起步。你要靠一次次行动、随机事件和考试结果，慢慢把自己练出来。

## 游戏亮点
 
- 周制推进的高中成长模拟，节奏更像真实校园生活
- 随机入学定位，不同开局会带来完全不同的逆袭体验
- 月考放榜、竞赛冲刺、老师关注、家庭压力、青春心动同时存在
- 多位 NPC 持续登场，校园关系会随着你的选择不断变化
- 高压状态下可能中途崩盘，不能一路无脑冲数值
- 支持打包为静态网页，适合部署到 GitHub Pages

## 适合谁

- 喜欢校园题材、成长题材、模拟经营的玩家
- 喜欢“从低起点一步步逆袭”这种成就感的人
- 想做一个能在网页里直接打开的中文独立小游戏的人

## 在线体验

如果你已经部署到 GitHub Pages，可以把链接放在这里：

`https://你的用户名.github.io/你的仓库名/`

## 本地运行

```bash
npm install
npm run dev
```

构建生产版本：

```bash
npm run build
```

运行测试：

```bash
npm test
```

## 项目结构

```text
src/
  components/   界面组件
  data/         事件、角色与文本内容
  lib/          游戏核心逻辑
  store/        状态管理
  tests/        核心流程测试
dist/           构建产物
scripts/        构建后处理与打包脚本
```

## 部署到 GitHub Pages

把以下内容上传到仓库根目录：

- `index.html`
- `assets/`
- `.nojekyll`

然后在仓库中打开：

`Settings -> Pages -> Deploy from a branch -> main -> /(root)`

保存后等待几分钟，GitHub Pages 就会生成可访问链接。

## 项目定位

这不是一个单纯的“学霸爽文模拟器”。

我更想做的是一种带有现实感的校园成长体验：
- 有排名焦虑
- 有竞赛机会
- 有家庭期待
- 有友情和心动
- 也有状态失控后直接结束一局的压力

如果你也曾经想过“要是能重新过一次高中，会不会走出不一样的路”，这个项目就是围绕这个念头做出来的。

## 说明

当前版本为网页原型，重点在玩法循环、事件体验和成长反馈。后续仍可以继续扩展：

- 更丰富的事件分支
- 更完整的 NPC 档案系统
- 更强的考试演出和结局展示
- 更细的竞赛与逆袭路线
